# ZEN Study 一括ダウンローダー (ZEN Study Downloader)

[![GitHub Release](https://img.shields.io/badge/release-v1.0.0-blue.svg)](https://github.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: Windows / Mac](https://img.shields.io/badge/platform-Windows%20%7C%20Mac-lightgrey.svg)]()

ZEN大学の講義動画および講義スライド画像を、**1クリックで全章一括ダウンロード・自動整理**できる公式受講生向けの快適学習支援ツールです。

---

## 🔒 セキュリティ・プライバシー方針（安心してご利用いただくために）

本ツールは受講生の安心と安全を最優先に設計されています。

1. **外部通信は一切なし（完全ローカル完結）**
   - アカウント情報、ID、パスワード、認証クッキー（Session）が**外部の第三者サーバーへ送信されることは絶対にありません**。
2. **すべての処理はご自身のPC内で実行**
   - ダウンローダー（サーバー）はお使いのPCの `localhost:5000` でのみ動作します。
3. **オープンソースで全コードを公開**
   - Chrome拡張機能およびPythonサーバーのすべてのソースコードを本リポジトリで公開しています。

---

## ✨ 主な機能

- 🎬 **コース全15章の一括ダウンロード**（各章に含まれる全動画を自動検出してダウンロード）
- 🖼️ **講義スライド画像の自動抽出・高画質保存**（動画ごとのスライドを `slides/` 内にページ順で自動保存）
- 📁 **章・動画・スライドの自動フォルダ分け＆番号整列**
  - 例: `01. イントロダクション/01_講義動画.mp4`
  - 例: `01. イントロダクション/slides/01_講義動画_slide_01.png`
- ⚙️ **画質選択・保存先フォルダの自由なカスタマイズ**（1080p / 720p / 480p / 360p）
- 🛡️ **他タブでの動画視聴と完全並行稼働**（バックグラウンド処理のため、他の動画を見ながらでも安全に一括保存可能）

## 🚀 かんたん導入手順（わずか2ステップ）

Pythonのインストールや黒い画面（コマンド操作）は**一切不要**です！

### ステップ 1: アプリ本体のダウンロード
1. 本リポジトリ右側の **[Releases](../../releases)** から最新の `ZEN_Study_Downloader_v1.0.zip` をダウンロードして解凍します。
2. 解凍したフォルダ内にある **`ZEN_Downloader.exe`** をダブルクリックして起動します。
   （「ZEN Downloader Server starting on port 5000...」と表示されれば準備完了です）

### ステップ 2: Chrome拡張機能の読み込み
1. Google Chrome を開き、URLバーに `chrome://extensions` と入力して開きます。
2. 右上の **「デベロッパー モード」** をONにします。
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダ内の **`chrome_extension`** フォルダを選択します。

## 📖 使い方

1. Google Chromeで通常通り [ZEN Study](https://www.nnn.ed.nico/) にログインし、ダウンロードしたい講義（コース）のページを開きます。
2. 画面右下に表示される **専用ボタン** をクリックするだけ！

| ボタン | 機能 |
| :--- | :--- |
| 🔥 **全15章（動画＋スライド）を一括ダウンロード** | コース全体の全動画と全スライドを一度に保存します |
| 🖼️ **スライド画像だけ一括ダウンロード** | 容量を節約したい方向け。全スライド画像のみを高速保存します |
| 📥 **この章の動画を一括ダウンロード** | 現在開いている単一の章のみを保存します |

## 🛠️ 開発者向け（ソースコードから起動する場合）

Python環境をお持ちの方は、ソースコードから直接起動することも可能です。

```bash
# 依存パッケージのインストール
pip install -r server/requirements.txt

# yt-dlpの配置（PATHが通っていれば不要）
# サーバーの起動
python server/zen_server.py
```

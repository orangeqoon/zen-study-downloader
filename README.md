# ZEN Study 一括ダウンローダー (ZEN Study Downloader)

[![GitHub Release](https://img.shields.io/badge/release-v2.0.0-blue.svg)](https://github.com/Orangeqoon/zen-study-downloader)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: Windows / Mac](https://img.shields.io/badge/platform-Windows%20%7C%20Mac-lightgrey.svg)]()

ZEN大学の講義動画（オンデマンド講義＆生放送アーカイブ対応）・講義スライド画像・確認テスト（解答解説・文字打ち込み正解表示・レポート課題付き）を、**1クリックで全章一括ダウンロード・自動整理**できる受講生向けの学習支援ツールです。

---

## 🔒 セキュリティ・プライバシー方針

受講生の安心と安全を最優先に設計されています。

1. **外部通信は一切なし（完全ローカル完結）**
   - アカウント情報、ID、パスワード、認証クッキーが**外部の第三者サーバーへ送信されることは絶対にありません**。
2. **すべての処理はお使いのPC内で実行**
   - ダウンローダー（サーバー）はお使いのPCの `localhost:5000` でのみ動作します。
3. **オープンソースで全コードを公開**
   - Chrome拡張機能およびPythonスクリプトのすべてのソースコードを本リポジトリで公開しています。

---

## 💡 なぜ「ローカルサーバー」が必要なのか？（仕組みと役割）

本ツールをご利用いただく際、Chrome拡張機能に加えて **ローカルサーバー（`start_server.bat` または `ZEN_Downloader.exe`）** を起動していただく必要があります。これには以下の明確な技術的理由があります。

1. **ブラウザのセキュリティ制約（ファイルシステム保護・CORS）の回避**
   - Webブラウザ内のJavaScript（拡張機能）はセキュリティ保護のため、PC内の自由なフォルダ階層（`D:\ZEN大学関係\...` 等）を自動作成したり、大容量動画ファイルを直接指定パスに書き込むことが禁じられています。
   - ローカルサーバーが橋渡しを行うことで、OSネイティブのファイル書き込み権限を行使し、章ごとのフォルダ階層（`movies/`, `slides/`, `exercises/`）を自動生成して綺麗に整列保存できます。

2. **超高速並列ダウンロード＆動画結合（ffmpeg / 24スレッド並列処理）**
   - 90分〜100分ある生放送アーカイブ講義は、約2,000個以上のHLS（TS）セグメントに分割されています。
   - これをブラウザ内だけで処理すると、メモリ不足でブラウザがフリーズしたりクラッシュしてしまいます。ローカルサーバー側でマルチスレッド高速並列取得＋`ffmpeg` による超高速無劣化結合を行うことで、長編動画でもわずか30秒〜1分程度で安全にMP4化できます。

3. **ブラウザを重くせず、他作業・動画視聴と完全並行稼働**
   - ダウンロード指示を出した後は、重いデータ処理をすべてバックグラウンドのローカルサーバーに任せるため、ブラウザ側では別の講義動画を快適に視聴したり、別の作業をストレスなく並行して行えます。

4. **完全なプライバシー保護（安全性の確保）**
   - クラウド上の外部サーバーではなく、**ご自身のPC内（`localhost:5000`）でのみ通信するローカルサーバー**を採用しているため、ログイン情報や個人データが外部インターネットに一切流出せず、安全に高速処理を実現できます。

## ✨ 主な機能

- 🎬 **講義動画の一括ダウンロード**
  - 通常のオンデマンド動画（`movie`）に加え、**生放送アーカイブ・ライブ映像講義（`lesson`）**の超高速並列ダウンロードに完全対応。
- 🖼️ **講義スライド画像の自動抽出・高画質保存**
  - 動画内のスライドを `slides/` 内にページ順（`01_講義名_slide_01.png`）で自動保存。
- 📝 **確認テスト・演習・レポート課題の一括画像収集**
  - **4択・選択式問題**だけでなく、**文字打ち込み式（正解文字列を緑色ハイライト表示）**や**確認レポート課題**も高画質PNGカードとして自動キャプチャ。
  - 各講義直下に `【確認テスト・演習まとめ】` フォルダを作成し、全15章分の演習を連番（`第01章_01_...`）で一括集約保存。
- 📁 **美しい自動フォルダ階層整理**
  - `講義名/01. 第1章タイトル/movies/01_動画.mp4`
  - `講義名/01. 第1章タイトル/slides/01_動画_slide_01.png`
  - `講義名/01. 第1章タイトル/exercises/01_確認テスト_問1.png`
  - `講義名/【確認テスト・演習まとめ】/第01章_01_確認テスト_問1.png`
- ⚙️ **画質選択（270p〜1080p）**
  - 容量を節約したい方向けの「270p（超軽量）」から「最高画質（1080p/720p）」まで自由に選択可能。
- 🛡️ **他タブでの視聴と完全並行稼働**

## 🚀 サーバーの起動方法

ダウンロードを実行する前に、ローカルサーバーを起動します。お好みの方法で起動できます。

### 方法 1: `start_server.bat` をダブルクリック（一番かんたん！）
リポジトリ直下の **`start_server.bat`** をダブルクリックするだけでサーバーが立ち上がります。

### 方法 2: コマンドライン（Python）から起動
```bash
python c:\scripts\zen_download_server.py
```
（`[Server] ZEN Downloader Server running on http://127.0.0.1:5000` と表示されれば準備完了です）

### 方法 3: スタンドアロンEXE（`ZEN_Downloader.exe`）
Releases から配布されている `ZEN_Downloader.exe` をダブルクリックして起動します。

## 🧩 Chrome拡張機能の導入

1. Google Chrome を開き、URLバーに `chrome://extensions` と入力して開きます。
2. 右上の **「デベロッパー モード」** をONにします。
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、本リポジトリ内の **`chrome_extension`** フォルダを選択します。

## 📖 使い方

1. Google Chromeで通常通り [ZEN Study](https://www.nnn.ed.nico/) にログインし、受講したい講義（コース）のページを開きます。
2. 画面右下に表示される専用ボタンをクリックします：

| ボタン | 機能 |
| :--- | :--- |
| 🔥 **全15章（動画＋画像）を一括ダウンロード** | コース全体の全動画と全スライドを一度に保存します |
| 🖼️ **スライド画像だけ一括ダウンロード** | 容量を節約してスライド画像のみを高速保存します |
| 📝 **確認テストだけ一括画像保存** | 全15章の確認テスト・演習・レポートを高画質画像で自動収集します |
| 📥 **この章の動画を一括ダウンロード** | 現在開いている単一の章のみを保存します |

## 🛠️ スタンドアロン用スクリプト（上級者向け）

コマンドラインから単体で実行することも可能です：

- **確認テスト・演習の一括画像収集**:
  ```bash
  python download_course_exercises.py <course_id> ["出力フォルダパス"]
  ```
- **生放送アーカイブ（ライブ講義）の高速ダウンロード（解像度指定可能）**:
  ```bash
  python download_live_course_videos.py <course_id> ["出力フォルダパス"] [270|720]
  ```
